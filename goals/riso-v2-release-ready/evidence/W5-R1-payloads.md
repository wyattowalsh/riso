### PAY-P0-fumadocs-static-metadata — P0

- **Files:** `template/files/node/docs/fumadocs/app/robots.ts.jinja`, `template/files/node/docs/fumadocs/app/sitemap.ts.jinja`

- **Why it breaks:** Next 16 static export requires `export const dynamic = "force-static"` or `export const revalidate` on those routes. Official default dest (`docs_framework: fumadocs`) smoke `samples/default/smoke-results.json` (timestamp `2026-08-14T06:11:56Z`):

```text
Error: export const dynamic = "force-static"/export const revalidate not configured
on route "/robots.txt" with "output: export".
Failed to collect page data for /robots.txt
```

  Dest `robots.ts` / `sitemap.ts` match the live jinja (no `dynamic` / `revalidate`). Residual `GATES.md` R2 named `/sitemap.xml`; the latest official default smoke failed first on `/robots.txt`. Same class — `sitemap.ts` will fail next if only robots is patched.
- **Fix (NODE):** Add `export const dynamic = 'force-static';` (or `export const revalidate = false;`) to both MetadataRoute modules. Do not restore `rewrites()` or `middleware.ts`. Re-render via `render-samples.sh` / `render_matrix.py`. Never hand-edit dest.
